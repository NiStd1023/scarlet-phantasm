# 緋夜幻彈 Scarlet Phantasm

直式瀏覽器彈幕射擊遊戲，支援電腦與觸控裝置。遊戲使用原生 HTML、CSS、Canvas 和 JavaScript；不需要安裝前端套件或編譯即可執行。

## 啟動開發環境

在專案根目錄執行：

```bash
python3 -m http.server 4173 --directory dist
```

以瀏覽器開啟 `http://localhost:4173/`。`dist/` 同時是實際原始碼與部署目錄；修改後重新整理瀏覽器即可查看。音樂播放可能需要先點擊遊戲按鈕，才能取得瀏覽器的播放授權。

## 專案結構

| 路徑 | 內容 |
| --- | --- |
| `dist/index.html` | 版面、遊戲按鈕與音樂元素 |
| `dist/style.css` | 電腦與手機版面樣式 |
| `dist/game.js` | 遊戲循環、角色、敵人、彈幕、碰撞、操作與音效 |
| `dist/manifest.webmanifest`、`dist/pwa.js`、`dist/sw.js` | 安裝設定、安裝按鈕與離線快取 |
| `dist/icons/` | 安裝圖示與 Apple 裝置圖示 |
| `dist/assets/`、`dist/key-art.png` | 角色與背景圖像 |
| `dist/music/` | 三個關卡與頭目配樂；音色檔及其授權文件位於 `licenses/` |
| `tools/generate_music.py` | 配樂作曲及音檔產生程式 |
| `tools/generate_pwa_icons.py` | 從現有角色圖產生 PWA 圖示（需要 Pillow） |
| `tests/` | 遊戲邏輯與配樂結構檢查 |
| `.openai/hosting.json` | 既有網站識別與靜態部署設定 |

## 驗證

```bash
node --check dist/game.js
node tests/game-logic.test.cjs
node tests/pwa.test.cjs
python3 tests/music-structure.test.py
```

遊戲邏輯測試需要 Node.js。配樂結構測試會載入作曲模組，需要 Python 3、NumPy 與 `libfluidsynth.so.3`；重新產生音樂時還需要 FFmpeg。一般遊玩與只修改網頁不需要這些音樂製作依賴。

## 安裝與離線遊玩

- Android：用 Chrome 開啟遊戲，選擇「安裝遊戲」或瀏覽器選單中的安裝／加入主畫面。
- iPhone、iPad：使用 Safari 開啟遊戲，點「分享」並選擇「加入主畫面」。
- 電腦：使用支援 PWA 的瀏覽器，可從網址列或選單安裝遊戲。

第一次請保持網路連線，等待遊戲素材與配樂完成快取；之後可從安裝圖示離線開啟。離線功能需要瀏覽器允許網站儲存資料，清除網站資料會移除快取和本機紀錄。兩個公開網址各自擁有獨立的安裝項目與本機紀錄。外部字型無法連線時會使用裝置的替代字型。

離線功能需要 HTTPS 或本機 localhost。每次更新預先快取的檔案，請遞增 `dist/sw.js` 的快取版本；變動 CSS 或 JS 時同步更新 `index.html` 和 service worker 清單中的版本參數。新版快取完整建立後才會取代舊版。

## 操作

- 方向鍵或 WASD 移動；按住 Shift 低速移動。
- 空白鍵或 X 發動 BOMB；P 或 Esc 暫停。
- 觸控裝置在畫面上拖曳移動，並使用「低速」與 BOMB 按鈕。
- 攻擊為自動射擊；拾取 P 升級武裝，拾取 B 補充 BOMB。
- 拾取 P、B 有不同的提示音；受擊時會播放音效並短暫震動畫面。提示音播放時配樂會短暫降低並平順恢復，讓音效更清楚。支援震動功能的裝置也會提供觸覺回饋，音效可用右上角音符按鈕關閉。

## 難易度

開始遊戲前可選擇 1～6 級；第 1 級維持原有難度，首次遊玩預設為第 1 級。難度選擇會儲存在目前瀏覽器，遊戲中與暫停時不會變更，結算後可重新選擇。

| 等級 | 名稱 | 挑戰特色 |
| --- | --- | --- |
| 1 | 初見 | 原有難度，熟悉操作與彈幕 |
| 2 | 緋光 | 敵彈速度與攻勢稍微提升 |
| 3 | 幻舞 | 一般敵人增加彈數，頭目彈幕更密集 |
| 4 | 狂瀾 | 敵人出現更頻繁，頭目耐久提高 |
| 5 | 血月 | 高速密集彈幕，考驗精準閃避 |
| 6 | 終焉 | 最快攻勢與最高敵方耐久 |

各級參數位於 `dist/game.js` 的 `DIFFICULTY_LEVELS`；變更後請執行遊戲邏輯測試，確認第 1 級、頭目攻擊和彈幕數量上限。

## 頭目彈幕設計

每個頭目有四招不同的攻擊，包含專屬彈型、配色、彈道與施法圖騰。一般敵人使用較簡潔的花瓣與菱晶彈，與頭目攻擊區別。

| 關卡 | 頭目 | 主要彈幕特色 |
| --- | --- | --- |
| 霧之森 | 道中・霧之守護者 | 紫色符印、羽毛與秘典法陣 |
| 霧之森 | 關底・霧之幻影 | 青紫幻蝶、水滴與漂浮弧線 |
| 緋月之庭 | 道中・緋月守衛 | 金色封印、符紙與交錯陣列 |
| 緋月之庭 | 關底・緋月之主 | 蝠翼、緋刃與薔薇旋舞 |
| 紅月終焉 | 道中・深紅使徒 | 咒印十字、紫焰與逆轉星環 |
| 紅月終焉 | 關底・紅月終焉 | 新月、星芒與日蝕法陣；低血量時強化攻擊 |

頭目設定與招式名稱位於 `dist/game.js` 的 `BOSS_PROFILES`，各招彈幕的產生方式位於 `pattern()`。修改時請兼顧辨識度、閃避空間與 `MAX_ENEMY_BULLETS` 上限。

## 部署與版本

既有網站的 `.openai/hosting.json` 將 `dist/` 指定為靜態部署目錄。更新網站時應沿用原有 Site 專案，先將變更納入 Git 版本，再從同一版原始碼封裝並發布。修改 `game.js` 或 `style.css` 時，請一併更新 `index.html` 中對應檔案的版本參數，避免瀏覽器沿用舊快取。請保留 `.openai/hosting.json` 與配樂授權文件；不要將登入憑證加入儲存庫。
